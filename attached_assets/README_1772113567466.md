# 🌾 Rize.farm WhatsApp → Slack Reporter

A WhatsApp chatbot that guides agronomists through structured bug reports or admin requests, auto-translates Indonesian/Vietnamese to English via Claude AI, and posts formatted cards to Slack.

## How It Works

```
Agronomist sends WhatsApp message
        ↓
Bot asks questions ONE at a TIME
        ↓
Validates answers (rejects garbage)
        ↓
Translates with Claude AI
        ↓
Posts formatted card to Slack
        ↓
Slack team reacts :done: / :solve:
        ↓
Bot notifies agronomist via WhatsApp
```

## Setup on Replit

### 1. Create a new Node.js Repl

### 2. Upload all files
Copy this folder structure into your Repl:
```
src/
  index.js
  session.js
  router.js
  flows/
    bugReport.js
    adminRequest.js
  services/
    wati.js
    slack.js
    translate.js
.env.example
package.json
```

### 3. Install dependencies
In the Replit Shell, run:
```bash
npm install
```

### 4. Set up Secrets (Environment Variables)
In the Replit **Secrets** tab (🔒 icon), add:

| Key | Where to get it |
|-----|-----------------|
| `WATI_API_ENDPOINT` | WATI Dashboard → API Docs → Your base URL |
| `WATI_TOKEN` | WATI Dashboard → API Docs → Bearer Token |
| `SLACK_WEBHOOK_BUG` | Slack App → Incoming Webhooks → #production-bug |
| `SLACK_WEBHOOK_ADMIN` | Slack App → Incoming Webhooks → #bugs-and-admin-requests |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `SLACK_SIGNING_SECRET` | Slack App → Basic Information → Signing Secret |

### 5. Run the bot
Click **Run** or in Shell:
```bash
npm start
```

### 6. Configure WATI Webhook
1. Go to WATI Dashboard → **Webhooks**
2. Set URL to: `https://your-repl-name.your-user.repl.co/webhook`
3. Enable message events

### 7. Configure Slack Events (for :done: / :solve: reactions)
1. Go to api.slack.com/apps → your app → **Event Subscriptions**
2. Turn ON
3. Request URL: `https://your-repl-name.your-user.repl.co/slack-events`
4. Subscribe to: `reaction_added`
5. Invite the bot to both channels: `/invite @Rize Bug Reporter`

## Commands for Agronomists

| Command | Action |
|---------|--------|
| `start` / `hi` / `halo` | Start a new report |
| `1` | Select Bug Report |
| `2` | Select Admin Request |
| `skip` | Skip optional questions |
| `kirim` / `submit` | Submit the report |
| `ulang` / `restart` | Start over |
| `cancel` / `batal` | Cancel everything |

## Conversation Flow

### Bug Report (7 questions)
1. What happened? (describe the bug)
2. Steps to reproduce (or SKIP)
3. Platform (Android/iOS/Web)
4. App version (or SKIP)
5. Account email/username
6. Related info: task/PG/farmer/season (or SKIP)
7. Screenshot/video (or SKIP)
8. Confirm → KIRIM / ULANG

### Admin Request (5 questions)
1. What do you need? (describe the request)
2. Account affected
3. Urgency (Low/Medium/High)
4. Additional context (or SKIP)
5. Screenshot (or SKIP)
6. Confirm → KIRIM / ULANG

## Translation
- Uses Claude AI (claude-3-haiku) for translation
- Only translates AFTER all data is collected (not during)
- Falls back gracefully if API key is not set
- Shows both original and translated text in Slack

## Architecture

| File | Purpose |
|------|---------|
| `src/index.js` | Express server, webhook routes |
| `src/session.js` | In-memory session store (30-min TTL) |
| `src/router.js` | Message routing + state management |
| `src/flows/bugReport.js` | Bug report state machine |
| `src/flows/adminRequest.js` | Admin request state machine |
| `src/services/wati.js` | WATI API wrapper |
| `src/services/slack.js` | Slack Block Kit formatter |
| `src/services/translate.js` | Claude AI translation |
