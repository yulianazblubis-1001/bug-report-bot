## Step 5: Handle Approvals & Rejections from Google Sheet
**IMPORTANT:** The source of truth for approval/rejection is the **Google Sheet**, NOT Slack. Ops Excellence will change the Status column (Q) directly in the Sheet. When that happens, we need to trigger actions.

1. Ops Excellence opens the Google Sheet
2. They review the request row
3. They change column Q (Status) from "PENDING" to "APPROVED" or "REJECTED"
4. If rejected, they also fill column T (Rejection Reason)
5. This triggers a **Google Apps Script `onEdit` hook** which calls your bot's webhook

```typescript
  // Body will contain: { requestId, status, reviewedBy, rejectionReason, slackTs, reporterPhone, reporterName, farmerName }
  // Handle APPROVED or REJECTED
});
```
**If status = APPROVED:**
- Add `:git-approved:` reaction to the original Slack message (using `slackTs` and `reactions.add` API)
