# Credit Limit Top-Up Form — Setup Guide

## Step 1: Install multer
In Replit Shell, run:
```
npm install multer @types/multer
```

## Step 2: Copy these files to your Replit project
Replace/add these files (same folder structure):

| File | Action |
|------|--------|
| `client/src/pages/credit-limit-form.tsx` | **NEW FILE** — add this |
| `client/src/App.tsx` | **REPLACE** existing file |
| `client/src/pages/dashboard.tsx` | **REPLACE** existing file |
| `server/routes.ts` | **REPLACE** existing file |
| `server/bot/router.ts` | **REPLACE** existing file |
| `server/bot/whitelist.ts` | **REPLACE** existing file |

## Step 3: Set environment variable
In Replit Secrets, add:
```
APP_URL = https://your-replit-app-url.replit.app
```
(This is the URL the bot sends to agronomists in WhatsApp)

## Step 4: Test
1. Restart your Replit app
2. Open your dashboard — you should see "Credit Limit Form" button in header
3. Click it — form should load with agronomist dropdown
4. Test the WhatsApp flow: START → 2 (Admin) → 2 (Credit Limit) → 1 or 2 → bot should send form link

## How it works
1. Agronomist chats on WA → picks Credit Limit → bot sends form link
2. Link auto-fills their name + credit type from URL params
3. Agronomist fills form + uploads docs → submits
4. Backend: uploads to Google Drive → writes Google Sheets → posts Slack card
5. Ops reviews in Sheets → approves/rejects
6. Agronomist gets WA notification
